# 华谦AI智能体・企业赋能 单页面官网

基于 PDF 内容（华谦AI智能体·企业赋能系统报价方案）一比一复刻的 React + Vite 单页面网站。

## 📋 项目信息

- **项目名称**：华谦AI智能体・企业赋能
- **配色方案**：主色 `#FF6B00`（橙色），辅助色 `#1a1a2e`（深蓝黑），强调色 `#00d4ff`（科技蓝）
- **参考结构**：https://huaqian.cc/
- **技术栈**：React + Vite + Tailwind CSS + AOS动画

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
